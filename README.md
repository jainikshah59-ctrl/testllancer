# Collancer Showcase 2.0

A redesigned Collancer showcase website using cinematic 3D glassmorphism, spatial UI, creator/brand storytelling, and an interactive CLEO AI demo.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The existing `public/` assets from the original Collancer project are retained. The Firebase/backend-heavy original app is intentionally not used by this showcase build so the presentation layer stays fast and independent.
